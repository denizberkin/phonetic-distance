Abstract

We study how to learn phonetic edit distances between names written in different scripts using only transliteration pairs. The method estimates directional character-to-character cost matrices without IPA labels, handcrafted correspondences, or gold character alignments.

The training procedure alternates between Dynamic Time Warping alignment and cost re-estimation. An initial matrix is derived from character co-occurrence counts; each iteration aligns the observed transliteration pairs, accumulates character pair frequencies along the minimum-cost paths, and normalizes those frequencies into the next cost matrix. English-to-target and target-to-English models are trained independently.

Method

For each language pair, the model learns a cost matrix over the source and target alphabets. The DTW path preserves character order while allowing one-to-one, one-to-many, and many-to-one correspondences.

  1. Initialization. Count cross-character co-occurrences over all transliteration pairs and convert the counts to costs using conditional probabilities.
  2. Alignment. Use DTW to find the minimum-cost path for each source-target pair under the current matrix.
  3. Re-estimation. Accumulate frequencies from the recovered paths, normalize the new matrix, and repeat until the normalized cost change converges.

Evaluation

Retrieval is evaluated by first narrowing candidates with a phonetic encoder and then ranking ambiguous candidates by learned DTW distance. The reported values are top-1 accuracy on multi-candidate buckets.

Target script Best top-1 accuracy Evaluation note
Greek 91.97% Best value over six phonetic filters
Armenian 93.53% Best value over six phonetic filters
Katakana 77.72% Best value over six phonetic filters
Russian 89.20% Best value over six phonetic filters

Retrieval accuracy is extrinsic evidence for the learned distances; it does not by itself prove that an inferred character alignment is linguistically unique.
